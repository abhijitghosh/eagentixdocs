# Step 04: On-Page Intelligence & Scorecards

The **On-page** pillar audits individual URLs against technical, structural, and semantic search standards.

---

## 1. Auditing a Target Page

To run an on-page audit:
1. Navigate to **Step 04: On-page**.
2. Enter the target page URL (or select one of your configured **Money Pages**).
3. Specify the primary target search term for that page.
4. Click **Run Audit**.

---

## 2. Page Type Checklist Scorecards

Different types of web pages have fundamentally different SEO requirements. SEO Studio tailors its audit scorecard to the detected page type:

- **Article / Blog Post**: Focuses on heading hierarchy (H1–H3), comprehensive coverage of subtopics, reading level, internal linking, and author E-E-A-T signals.
- **Product / Service Page**: Focuses on transactional schema (`Product`, `Offer`), value propositions above the fold, reviews/ratings, and conversion CTAs.
- **Homepage / Category**: Evaluates site architecture, topical clusters, and crawl depth.

---

## 3. Side-by-Side Competitor Benchmarking

You can compare your target page directly against top-ranking competitor URLs:
- Word count and content depth
- Keyword density and semantic entity mentions
- Image alt tag coverage
- Open Graph and structured data markup

::: danger Honest Scoring Guarantee
SEO Studio **never scores a page it could not fetch**. If a competitor page blocks automated user-agents or returns a 403/500 HTTP error, the system reports the crawl error explicitly rather than fabricating an arbitrary score.
:::
